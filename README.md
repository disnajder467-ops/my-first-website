# PC Forge — симулятор сборки ПК

## Запуск в Visual Studio Code
1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Откройте `index.html` в браузере. Можно установить расширение Live Server и нажать **Go Live**.
4. Интернет для локального запуска не требуется.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий на https://github.com/new
2. Загрузите `index.html` в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`, branch `main`, folder `/(root)`, затем Save.
5. Дождитесь публикации и откройте ссылку, показанную на странице Pages.

Цены в сомах и оценка FPS условные, учебные. Проверка совместимости упрощённая.
